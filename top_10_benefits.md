# Top 10 Benefits of Culebra AI Spell Correct

1. **Context-Aware Error Correction**
   - **Benefit:** Fixes spelling, grammar, punctuation, and typos based on sentence context rather than basic dictionary lookup.
   - **Example:** Automatically resolves confusing homophones like "their vs there" or "affect vs effect".

2. **Strict Markdown & Formatting Preservation**
   - **Benefit:** Never damages Markdown formatting, headings, links, tags, or code snippets during correction.
   - **Example:** Leaves ````python def test(): pass````, `[[WikiLinks]]`, and `#tags` intact while fixing surrounding prose.

3. **Cultural & Vernacular Name Protection**
   - **Benefit:** Recognizes and preserves Indian names, places, organizations, and cultural terminology without flagging them as errors.
   - **Example:** Retains terms like "Bengaluru", "Aadhaar", or person names like "Siddhartha" without garbling or misspelling them.

4. **Targeted Selection or Full-Note Correction**
   - **Benefit:** Choose to correct an entire note or just a highlighted sentence/paragraph.
   - **Example:** Highlight a messy pasted paragraph and run *Culebra: Correct selected text* without touching the rest of your note.

5. **One-action corrections**
   - **Benefit:** Apply the correction when you run the command and use Undo for editor changes if needed.
   - **Example:** Inspect a side-by-side diff modal showing additions in green and deletions in red before committing.

6. **File Explorer Context Menu Integration**
   - **Benefit:** Clean up Markdown files directly from Obsidian's file tree without opening them first.
   - **Example:** Right-click a newly imported note in the file explorer and click *Culebra: Correct note*.

7. **Custom OpenRouter AI Model Selection**
   - **Benefit:** Switch between fast, cost-effective models or deep reasoning models depending on your budget and accuracy needs.
   - **Example:** Choose a lightweight model for quick typos or a flagship model for complex technical drafts.

8. **Bring Your Own Key (BYOK) or Built-In Access**
   - **Benefit:** Flexibility to use your personal OpenRouter API key or start immediately with zero setup.
   - **Example:** Optionally add a personal OpenRouter key in settings to override the built-in key.

9. **Safety & Full Undo Support**
   - **Benefit:** Revert corrections instantly if the result does not match expectations.
   - **Example:** Press `Ctrl+Z` / `Cmd+Z` immediately after applying to restore your exact original text.

10. **Free Starter Allowance**
    - **Benefit:** Start correcting immediately upon installation with no account or upfront payment required.
    - **Example:** Clean up first drafts right away using the complimentary 2,000-character starter credit.
