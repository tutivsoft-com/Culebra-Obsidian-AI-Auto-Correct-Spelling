# Culebra public mirror analysis

This public repository mirrors the validated plugin surface from the private Culebra source repository. Billing is account-scoped and authenticated; free usage and paid spend are server-authoritative. Support diagnostics intentionally exclude note contents, tokens, and credentials. Build, diff-check, and publish parity are validated in the private source before mirroring. No vault data, deployment, commit, or push is part of this work.
