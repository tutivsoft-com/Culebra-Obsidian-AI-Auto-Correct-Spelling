# Marketing Overview

## Product summary

Culebra AI Spell Correct helps Obsidian users correct spelling, grammar, punctuation, capitalization, and obvious typing mistakes while keeping the intended meaning and Markdown structure under the user's control.

## Who it serves

Culebra is for people who draft and maintain Markdown notes in Obsidian, including students, writers, researchers, and technical note-takers.

## Product benefits

- Work on a selection, the current note, or a Markdown file from the file explorer.
- Review the suggested correction before applying it; cancel without changing the note.
- Keep links, code, frontmatter, wiki links, and other Markdown structures intact.
- Preserve Indian names, places, organizations, and common Indian English wording.
- Choose an OpenRouter model and use the account-linked starter allowance or optional credit packs.

## Trust and privacy

The user explicitly starts each correction. The text being corrected is sent to the configured OpenRouter model. TutivSoft Constance receives billing and installation details for account linking and credit usage. Users should not send confidential notes unless they accept remote processing by the configured provider.

## Short description

Review-first AI spelling and grammar correction for Obsidian, with Markdown-aware safeguards and a clear preview before edits are applied.
