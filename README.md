# Culebra AI Spell Correct

Version: 4.4.42

Correct selected text, the current note, or Markdown files while preserving meaning and Markdown structure. Text selected for correction is sent through the managed AI service; no personal provider key is required.

## Billing and current offers

The plugin displays the exact current price, product description, availability, and included characters returned by the live Constance catalog. Prices and included amounts are not hardcoded in this README or used as a fallback. If the catalog or billing policy is unavailable, purchase controls stay unavailable. Payment is confirmed by the server before account credits are updated.

Usage is measured in characters submitted for the authorized operation.

## Privacy

Only content needed for an operation you start is sent to the service that performs it. Avoid submitting sensitive vault content unless you have reviewed the applicable provider terms. The plugin does not require you to provide a personal AI provider key.

## Installation

Install **Culebra AI Spell Correct** from Obsidian Community plugins, then enable it in Settings → Community plugins.
